# 项目总结文档

## 项目概述

**项目名称**: 遗传算法求解迷宫问题  
**版本**: 1.0.0  
**创建日期**: 2025-10-27  
**编程语言**: Python 3.x  

## 项目目标

本项目旨在实现一个完整的遗传算法系统，用于求解迷宫路径规划问题。通过模拟自然界的进化过程，算法能够自动寻找从起点到终点的可行路径。

## 核心功能

### 1. 迷宫生成 (maze.py)

- **Maze类**: 完整的迷宫表示和操作
- **随机生成**: 自动生成具有可调复杂度的迷宫
- **路径验证**: 检查位置有效性和邻居关系
- **距离计算**: 曼哈顿距离计算

**关键特性**:
- 可配置的迷宫尺寸
- 可调节的复杂度和密度参数
- 保证起点和终点可达

### 2. 遗传算法 (genetic_algorithm.py)

- **Individual类**: 表示单个路径解决方案
- **GeneticAlgorithm类**: 完整的遗传算法实现

**核心操作**:
- **选择**: 锦标赛选择（tournament size=5）
- **交叉**: 单点交叉，带路径修复机制
- **变异**: 随机路径片段重生成
- **精英保留**: 保护最优个体

**适应度函数设计**:
```
到达终点: 基础分 10000 + 步数奖励 + 唯一性奖励
未到达:   距离分 1000/(1+距离) + 长度奖励 + 唯一性奖励
```

### 3. 可视化 (visualizer.py)

- **静态图表**: 迷宫结构和路径可视化
- **演化曲线**: 适应度历史记录图表
- **对比分析**: 多结果对比功能
- **动画支持**: 路径搜索过程动画（可选）

### 4. 主程序 (main.py)

**三种运行模式**:
1. **basic**: 基础示例演示
2. **comparison**: 参数对比实验
3. **custom**: 自定义参数运行

**命令行参数**:
- `--mode`: 运行模式选择
- `--width/--height`: 迷宫尺寸
- `--population`: 种群大小
- `--generations`: 最大代数
- `--mutation`: 变异率

### 5. 测试套件 (tests/run_tests.py)

**五大测试模块**:
1. 迷宫生成验证
2. 小迷宫求解测试
3. 中等迷宫求解测试
4. 算法稳定性测试
5. 不同尺寸迷宫测试

## 技术实现

### 算法参数说明

| 参数 | 默认值 | 说明 | 推荐范围 |
|------|--------|------|----------|
| population_size | 100 | 种群大小 | 50-500 |
| max_generations | 500 | 最大代数 | 200-2000 |
| mutation_rate | 0.15 | 变异概率 | 0.05-0.3 |
| crossover_rate | 0.7 | 交叉概率 | 0.6-0.9 |
| elitism_count | 2 | 精英数量 | 1-5 |
| max_steps | 200 | 单个体最大步数 | 迷宫大小×2 |

### 性能特点

**优势**:
- 不需要完整地图信息即可工作
- 能够找到可行解（非最优解）
- 适合复杂、动态环境
- 易于并行化

**局限**:
- 不保证找到最短路径
- 计算时间较长
- 需要调参
- 随机性导致结果不稳定

### 与其他算法的对比

| 算法 | 最优性 | 速度 | 内存 | 适用场景 |
|------|--------|------|------|----------|
| 遗传算法 | 近似解 | 慢 | 中 | 复杂优化、无先验知识 |
| A* | 最优解 | 快 | 高 | 静态迷宫、已知地图 |
| DFS/BFS | 可行解/最优解 | 中 | 高 | 简单迷宫 |
| 强化学习 | 近似解 | 很慢 | 高 | 动态环境、学习型任务 |

## 已知问题

1. **matplotlib中文显示**: 部分系统可能需要配置中文字体
   - 解决方案: 安装SimHei字体或使用英文标签

2. **大迷宫性能**: 超大迷宫(>50×50)可能运行缓慢
   - 解决方案: 减少种群大小或启用并行计算

3. **随机性**: 结果存在较大随机性
   - 解决方案: 多次运行取平均或增加种群规模
