## 常见问题解答

### Q1: 如何开始使用？

**A**: 按照以下步骤：
```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行示例
python example_simple.py

# 3. 查看文档
cat README.md
```

### Q2: 算法找不到解决方案怎么办？

**A**: 
- 增加种群大小（如200）
- 增加代数（如1000）
- 降低迷宫复杂度
- 检查迷宫是否可解

### Q3: 如何修改算法参数？

**A**: 使用自定义模式：
```bash
python src/main.py --mode custom \
    --population 200 \
    --generations 1000 \
    --mutation 0.2
```
